    Commander une création

    Tout est fait à la main et à la demande. Voici comment ça se passe :

    1. Vous me décrivez votre idéePrénom, thème, couleurs, occasion. Le formulaire ci-contre prépare le message pour vous.
    2. Je vous envoie une propositionAvec le prix et le délai. On ajuste ensemble si besoin.
    3. Vous validez la maquetteJe vous envoie une maquette de votre création. Vous validez, ou on ajuste ensemble.
    4. Je fabrique votre créationLe chef de l'atelier fait le contrôle qualité.
    5. Vous la recevezEn main propre ou par envoi, selon ce qui vous arrange.
